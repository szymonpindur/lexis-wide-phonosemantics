All cell tables preserve raw/adjusted p-values, eligibility and status, selected-control counts, coefficients, SEs and pointwise intervals. Ineligible bookkeeping p=1 is not an observed inferential p-value. Source aliases may occur in more than one provenance category.

Hosting and distribution

This is a buildless static resource, with relative links and a local Plotly bundle. It can be hosted on GitHub Pages or another static host and opened offline. No raw corpus sentences, transformer weights, dictionaries, annotation proposal batches, credentials or local machine paths are included. Table and example-word redistribution should follow your project’s data/licensing policy; no new blanket dataset license is assigned here.

The separate package README gives the publication steps. GitHub’s official Pages instructions.
